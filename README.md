# دليل البحر والقوارب

موقع تفاعلي عن عالم القوارب والإبحار — مبني بالكامل من الصفر بـ HTML و CSS و JavaScript.

[زيارة الموقع المباشر](https://weadalamari.github.io/اسم-المستودع/)

![معاينة الموقع](preview.png)

---

## فكرة المشروع

دليل شامل بالعربية والإنجليزية والصينية يحتوي على:

- خطوات بناء قارب
- الطقس والمد والجزر
- كتب بحرية موثوقة
- مواقع تعليمية
- قنوات يوتيوب متخصصة
- قاموس بحري بأكثر من 180 مصطلح

وإذا أردت تشغيله محليًا، حمّل الملفات من المستودع وافتح `index.html` في أي متصفح.

---

## التقنيات المستخدمة

- HTML5 — بنية الصفحات
- CSS3 — التصميم والحركات والخلفيات المائية
- JavaScript (Vanilla) — الترجمة والبحث والتفاعل
- SVG — كل الرسومات والأيقونات (بدون صور خارجية)

---

## ما تعلمته من المشروع

- بناء موقع متعدد اللغات بنظام ترجمة مخصص من الصفر
- تصميم خلفيات Watercolor بـ CSS Gradients
- رسم مشاهد بحرية كاملة بـ SVG بدون صور
- إدارة LocalStorage لحفظ تفضيلات المستخدم
- كتابة JavaScript نظيف بدون مكتبات خارجية
