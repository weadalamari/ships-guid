عن الموقع
موقع بسيط يجمع معلومات عن القوارب والسفن. فيه شرح لبناء القوارب، معلومات عن الطقس والمد والجزر، مكتبة كتب، مواقع تعليمية، قنوات يوتيوب، وقاموس بحري.
أهم شيء فيه أنه يدعم ثلاث لغات: العربية والإنجليزية والصينية. تقدر تبدل اللغة من أي صفحة وتشوف المحتوى كامل بلغة ثانية.
